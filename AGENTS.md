# AGENTS.md

As orientações para agentes de IA deste projeto moram no
[`CLAUDE.md`](CLAUDE.md). O nome é do Claude Code, mas **elas valem para
qualquer IA** — Codex, Cursor, Copilot, Gemini ou outra.

**Leia o `CLAUDE.md` inteiro antes de qualquer coisa.** A primeira seção dele
decide o que fazer: se não existe um arquivo `.env` na raiz, esta é uma
**instalação nova**, e a pessoa quer colocar o sistema no ar — o caminho é o
[`INSTALACAO.md`](INSTALACAO.md), e o `CLAUDE.md` diz o que é seu e o que é
dela.

> Este arquivo existe porque cada IA procura as instruções num lugar: o Claude
> Code lê o `CLAUDE.md`; o Codex e o Cursor, o `AGENTS.md`. As regras ficam num
> lugar só — duas cópias, um dia, discordariam.
